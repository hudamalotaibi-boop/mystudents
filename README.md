# رحلتي في تعلم HTML

موقع تعليمي تفاعلي باللغة العربية، يعمل كملفات ثابتة دون تثبيت مكتبات.

## التشغيل محليًا

افتحي `index.html` في متصفح حديث. تُحفظ بيانات الاسم والصف والإجابات على الجهاز نفسه في `localStorage`، ولا تُرسل إلى خادم.

## نشره عبر GitHub Pages

1. ارفعي الملفات `index.html` و`style.css` و`script.js` و`.nojekyll` إلى جذر مستودع GitHub.
2. من إعدادات المستودع افتحي **Pages**.
3. اختاري النشر من فرع `main` ومجلد الجذر `/` ثم احفظي.
4. سيظهر رابط النشر في صفحة Pages بعد اكتمال البناء.

> لا يحتوي الموقع على قاعدة بيانات مركزية؛ كل طالبة ترى وتحفظ تقريرها في متصفحها. يمكن للطالبة طباعة تقريرها لمشاركته مع المعلمة.
