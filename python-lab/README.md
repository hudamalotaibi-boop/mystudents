# مختبر بايثون

محرر تعليمي باتجاه RTL، يضم شاشة ترحيب باسم المعلمة هدى العتيبي، وإدخال اسم الطالبة، ومفسر Python حقيقي داخل المتصفح. واجهة المحرر والأمثلة البرمجية بالإنجليزية، وأسماء دروس المنهج بالعربية.

## التشغيل

افتحي `index.html` من استضافة ويب في متصفح حديث، مع اتصال بالإنترنت لتحميل Pyodide من CDN عند أول تشغيل. لا يحتاج المشروع إلى تثبيت أو بناء.

## حدود المحاكي

يشغّل المحرر Python عبر Pyodide، ويدعم تراكيب اللغة القياسية والمكتبات القياسية والملفات الافتراضية، كما يوفر محاكاة متصفح مبسطة لعناصر Tkinter الشائعة: `Tk`, `Label`, `Entry`, `Button`, و`Text` مع `pack` و`grid`. لا يدعم فتح نوافذ سطح المكتب الحقيقية أو جميع تفاصيل Tkinter، ولا يضمن عمل مكتبات خارجية غير متاحة في Pyodide.

تتضمن الأمثلة الصفوف والقوائم والقواميس والقوائم المتداخلة والمكتبات والملفات والشروط والتكرار والواجهات الرسومية.
